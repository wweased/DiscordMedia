# DiscordMediaRPC - дизайн приложения

## Идея

Приложение читает системную медиа-сессию Windows (что сейчас играет в браузере или в десктоп-плеере - SoundCloud, YouTube Music, любой источник) и транслирует это в Discord через Rich Presence, аналогично тому, как это делает встроенная интеграция со Spotify.

## Стек

- C# WPF, .NET Framework 4.8, старый формат csproj
- Microsoft.Windows.SDK.Contracts - доступ к GlobalSystemMediaTransportControlsSessionManager (WinRT API)
- DiscordRPC (nuget) - отправка статуса в Discord через Rich Presence

## Архитектура

```
+-------------------+       +----------------------+       +----------------+
| СлушательМедиа     | ----> | ФорматированиеСтатуса | ----> | ОтправительDiscord |
| (WinRT сессия)     |       | (трек, автор, обложка)|       | (DiscordRPC)   |
+-------------------+       +----------------------+       +----------------+
          ^
          |
   Изменение трека (событие)
```

### 1. СлушательМедиа

- Получает `GlobalSystemMediaTransportControlsSessionManager`
- Подписывается на событие смены текущей сессии и смены свойств трека (`MediaPropertiesChanged`)
- Достаёт: название трека, исполнителя, состояние (играет/пауза)

### 2. ФорматированиеСтатуса

- Собирает строку для Discord: `Details` = название трека, `State` = исполнитель
- Обложка трека в Rich Presence напрямую не показывается (Discord Assets требуют заранее загруженных картинок в Developer Portal) - на первом этапе используется статичная иконка приложения

### 3. ОтправительDiscord

- Инициализация через `DiscordRpcClient` с `Client ID` приложения, зарегистрированного в Discord Developer Portal
- Обновление `Presence` при каждом изменении трека
- Очистка Presence при закрытии приложения или остановке воспроизведения

## Визуальный дизайн

Референс - не музыкальный сервис, а бытовая аппаратура: кассетный дек, эквалайзер, VU-метр. Приложение показывает "что играет" так, как это делал бы физический индикатор на деке, а не карточка в духе стриминговых сервисов.

### Цвет

- `#14120F` - фон окна, тёплый почти-чёрный (не чистый чёрный)
- `#1E1B17` - панель/подложка элементов
- `#E8A33D` - акцент (стрелка VU-метра), только для активных состояний
- `#C1443C` - индикатор паузы/остановки, используется точечно
- `#EDE6DA` - основной текст, тёплый белый
- `#8A8177` - второстепенный текст, подписи

### Типографика

- Заголовок трека и исполнитель - **Bahnschrift SemiBold Condensed** (встроен в Windows 10/11, узкий и характерный, не дефолтный Segoe UI)
- Числовые индикаторы (таймер, статус) - **Cascadia Mono** (тоже системный шрифт, моноширинный - обоснованно, потому что имитирует сегментный дисплей аппаратуры, а не используется как случайная деталь для лейблов)

### Layout

Компактный вертикальный виджет, без скруглений, без теней - плоская панель с тонкой окантовкой, как корпус устройства:

```
+--------------------------------------+
| o  DISCORD                            |
|                                        |
|  Название трека переносится            |
|  на вторую строку при надобности       |
|  Исполнитель                          |
|                                        |
|  ||||||||||||...........  1:42 / 3:20 |
+--------------------------------------+
```

Выравнивание - по левому краю, без центрирования (как у реальных индикаторов на панели). Статус подключения - не бейдж, а точка-индикатор (o) + короткая подпись.

### Принципы

- Один акцентный цвет (амбер), всё остальное - нейтральные тёмные и тёплые тона
- Никаких скруглённых карточек и мягких теней - флэт-панель с окантовкой в 1px
- Прогресс-бар выглядит как счётчик ленты на деке, а не стандартный слайдер Material
- Без ALL CAPS лейблов и стрелок в тексте
- Кнопка "Свернуть в трей" - иконка, не текстовая кнопка, чтобы не перегружать компактный виджет

### Проверка на клише

Не тёплый крем + терракота (дефолт ИИ-дизайна), не SaaS-карточки с тенями, не broadsheet-вёрстка. Тёмная тема с одним акцентом близка к паттерну "почти чёрный + неон", но здесь фон тёплый (не #0B0B0B), акцент приглушённый амбер (не кислотный), а моноширинный шрифт обоснован метафорой аппаратного дисплея, а не использован по умолчанию для лейблов.

## Интерфейс (MVP)

Минимальное окно:
- Статус подключения к Discord (точка-индикатор + подпись)
- Текущий трек и исполнитель, с переносом строки
- Прогресс-бар в виде счётчика ленты
- Кнопка-иконка "Свернуть в трей"

## Ограничения на первом этапе

- Обложка трека не передаётся (нужна доработка через Discord Assets)
- Работает только на Windows 10/11 (WinRT API недоступен на более старых системах)
- Discord Rich Presence не различает источник (SoundCloud/YouTube Music/другое) - показывает то, что видит система
