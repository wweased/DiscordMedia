# Медиа для Discord

Показывает в статусе Discord то, что играет в любом медиаплеере на компе (браузер, SoundCloud, YouTube Music и т.д.).

## Как поставить (если у тебя уже была старая версия проекта)

1. Удали текущую папку проекта у себя на компе и распакуй этот архив заново поверх — легче, чем чинить руками.
2. Открой `DiscordMediaRPC.csproj` в Visual Studio.
3. Она увидит `PackageReference` в файле проекта и сама предложит восстановить пакеты (или сделай это сама: правой кнопкой по решению → Restore NuGet Packages).
4. Дождись, пока скачаются `DiscordRichPresence` и `Dubya.WindowsMediaController` — второй пакет решает всю боль с системным Windows Media API, включая нужные настройки WinRT, за нас.
5. Зайти на https://discord.com/developers/applications, создать приложение, скопировать `Client ID`, вставить в `MainWindow.xaml.cs` вместо `СЮДА_CLIENT_ID_ИЗ_DISCORD_DEVELOPER_PORTAL`.
6. Собрать и запустить (F5). Discord должен быть открыт и запущен на этом же компе.

## Если ставишь с нуля

То же самое, просто без шага 1.

## Ограничения

- Работает только на Windows 10/11 (используется системный API медиа-сессий).
- Обложка трека в статусе не показывается - это отдельная доработка через Discord Assets (нужно заранее загружать картинки в Developer Portal).
- Не собирал и не проверял на компиляцию в песочнице - тут нет Windows и WPF-тулчейна для сборки. Если при первом запуске вылезет ошибка компиляции, скинь текст ошибки - поправлю.
